# Animal Shelter & Adoption Management System

GitHub Pages website for the OOPS Through Java project.

## Files
- `index.html` - project website
- `style.css` - website styling
- `script.js` - animal filter interaction
- `src/Main.java` - Java project source (add your Java source here)
- `docs/` - project documentation

## GitHub Pages
Create a public repository, upload these files, then go to:

**Settings → Pages → Build and deployment → Deploy from a branch → main → / (root) → Save**

The live site will normally be:
`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`
