About the Project

The system replaces scattered manual records with an organized object-oriented model for an animal shelter.

It models animals, adopters, adoptions and the shelter as Java classes. The system can add animals, register adopters, search by identifier, check availability and maintain adoption records.

Objectives

  • Maintain animal records efficiently.
  • Store adopter information.
  • Manage the adoption process.
  • Track available and adopted animals.
  • Demonstrate Java OOP concepts.
  • Use ArrayList collections.

Java OOP Concepts

01

Encapsulation

Animal data members are private and accessed through public methods such as getters and setters.

02

Inheritance

Dog, Cat and Bird extend the abstract Animal class and reuse common attributes and behavior.

03

Polymorphism

Overridden getType() and makeSound() methods provide different behavior for different animal objects.

04

Abstraction

Animal is abstract and defines the common contract for concrete animal subclasses.

Example: Inheritance & Polymorphism
abstract class Animal {
    public abstract String getType();
    public abstract void makeSound();
}

class Dog extends Animal {
    public String getType() { return "Dog"; }
    public void makeSound() { System.out.println("Woof!"); }
}
